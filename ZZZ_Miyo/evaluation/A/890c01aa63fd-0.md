# 「扳机」—对话与信赖

- **Soldier 11：** 我认为我们已经在这里得到充分的休息了。「扳机」，是时候回去复命了。

- **「扳机」：** 唔…再稍微晚一点吧！我答应过奥菲丝，要给她偷偷带些零食回去的…

- **Soldier 11：** 那我们应该离开这艘帆船，去商店逛逛，而不是在这里俯瞰整个度假村。这里不是战场，并不存在你需要占据制高点来锁定的目标。

- **「扳机」：** 〔哲视角〕目标的话…当然有的！刚才和你对话分了会心，丢失了他的方位…我正在感知气息，重新锁定他的行踪…

- **「扳机」：** 〔铃视角〕目标的话…当然有的！刚才和你对话分了会心，丢失了她的方位…我正在感知气息，重新锁定她的行踪…

- **「扳机」：** 〔哲视角〕…我再次捕捉到他的气息了！他现在就在…诶？！

- **「扳机」：** 〔铃视角〕…我再次捕捉到她的气息了！她现在就在…诶？！

- **「扳机」：** …绳、绳匠，你是什么时候…离我们这么近的…

> - **「扳机」：** 这、这样吗…看样子是我过于松懈了，本来应该第一时间感知到你的靠近的…

> - **「扳机」：** 开、开心吗…谢谢你，我也是这么想的，绳匠…

- **Soldier 11：** 「灼人的伊卡洛斯」，原来你也在这里度假吗？看来「扳机」坚持要从卫非地坐好一阵子车来这边放松，并不是一时的心血来潮呢。

- **「扳机」：** 呜…「11号」！

- **Soldier 11：** 我的发言有什么问题吗？能在选择小憩的场所遇到重要的伙伴，本就是一件很让人开心的事情。能够主动制造这种情境，是你作为一名优秀士兵的「证明」。

- **「扳机」：** 你说的都对…你说得都对啦，所以拜托别说了，太羞耻了…
