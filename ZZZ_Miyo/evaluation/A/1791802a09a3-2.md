# 「扳机」—敲敲通讯

- **「扳机」：** 但另一位绳匠说你不在。在店里坐了一会都没等到你…我就回去了。

- **「扳机」：** 不是遇上麻烦就好…下次如果约定有变化，提前告诉我，我会更改日程安排的。

- **「扳机」：** 作为补偿，下次可不能失约哦。

- **主角（哲／铃）：** 去「光映广场」按摩吗？

- **「扳机」：** 按摩…是说那家「杜伊老爹体态工作室」吗？

- **「扳机」：** 我听说过这家店。哪怕是在防卫军内部，他家手艺也很有名。

- **「扳机」：** 谢谢你这么关照我，绳匠。你平日处理委托和打理店面一定也很辛苦吧，就让我们一起放松一下吧。

- **「扳机」：** 说实话，我也挺好奇按摩的感觉的…会很痛吗？还是会很痒？

- **「扳机」：** 我们在光映广场的停车场见面吧。总感觉会是一次很新奇的体验…

- **「扳机」：** 绳匠，昨天你没有赴约，我一个人在按摩店门口徘徊了很久…然后回军营了。

- **「扳机」：** 独自去尝试之前未曾有过的体验，对我来说还是难度太高了。

- **「扳机」：** 那说好了哦。

- **「扳机」：** 说起来，在等你的时候，我碰见了一头很可爱的狗狗…我就当那是你派来陪我的，逗它玩了很久。结果它的主人过来了，告诉我…

- **「扳机」：** …到底告诉了我什么，等下回你再约我出来而且没失约的时候再告诉你哦。

- **主角（哲／铃）：** 去野火镇吃顿饭？

- **「扳机」：** 野火镇…是外环的那座小镇吗？

- **「扳机」：** 我知道的。绳匠，可不要小瞧我的情报网哦。

- **「扳机」：** 那我们一起去吃顿饭吧。最近侦察潜伏类任务有些多，我光吃红豆包了…有必要丰富一下营养摄入。

- **「扳机」：** 吃饭之余，可以多和我一起逛逛外环吗？我们就在野火镇的上层见面？
