# 「扳机」—对话与信赖

- **Soldier 11：** 如果要到录像店做饭，记得叫上我。我也想和我的好搭档一起吃饭。

- **「扳机」：** 知道啦…会带上你的。明天作战结束试试我做的地狱辣拉面？

- **「扳机」：** 你的意思是，你的同伴们…

- **安比·德玛拉：** 嗯。他们大体就是这种感觉。

- **「扳机」：** 你是说，一位把在丁尼里泡澡视作人生理想的少女，一个憧憬成为星徽骑士的智能构造体，一只会在几个月前的深夜偷你布丁吃的野猫…

- **「扳机」：** …再加上你，就是「狡兔屋」的所有成员构成？

- **安比·德玛拉：** 是的。我尝试提炼出了我的同伴们的特点里，最值得你关心的部分。相信你应该能感受到他们的价值所在。

- **「扳机」：** 原来如此。那位爱财的少女有着极强的内驱力，只要报酬到位，就可以给雇主足够满意的交代。

- **「扳机」：** 那位智能构造体，一方面有着极强的正义感，另一方面并不满足于自己眼下的实力，希望能持续成长到虚构作品里的强度，有很高的成长潜力。

- **「扳机」：** 至于那只野猫…能在你的眼皮底下偷吃布丁，而且让你持续记了几个月，实力也不容小觑。

- **「扳机」：** 我相信他们都拥有足以让我安心的能力。

> - **安比·德玛拉：** 我已经很客观了。猫又的实力以及她应该被虚狩逮捕的罪证都在这个事例中得到了充分展示。

- **「扳机」：** 绳匠，我正在和安比谈合作呢…当然，是瞒着「11号」的。也请你对「11号」保密。

- **「扳机」：** 「白银的复苏」事件让我见识到了安比的实力。说实话，防卫军如果能有她这样的战力协助，很多棘手的任务都可以迎刃而解。

- **「扳机」：** 只可惜军方高层抗拒和盗洞客进行合作…不过我并不抗拒，而且我也不打算事事听命于高层的大人物们。
