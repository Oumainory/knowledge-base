# 侵蚀症状·叙事描述

身与心一同变得衰弱，渺小得如同空洞中的残骸。

有一种莫名的抵触感…这东西和以骸的气息太像了，不会是它们的胚胎吧？

「完了，这下全完了！」

「我刚才打了个喷嚏，是不是要死了？」

特殊而细微的以太环绕在队员周身挥之不去，这似乎对以骸有一定的活化作用。

汹涌的斗志逐渐干涸，战斗变得只是为了活下去而已。

令人不敢轻易喘息。

心中的不安左右摇摆，似有似无，愈演愈烈。

不知为何，大家的心性变得暴躁强硬了起来，连邦布商人都招架不住。

「别慌，别慌…」

「只要手里还有齿轮硬币，就一定能在空洞里活下来…」

你感觉适应了躁动以太带来的灼痛，正逐渐与空洞融为一体…而这往往是崩溃的前兆。

被击败的敌人爆散出强烈的以太，沐浴在其中就会感到前所未有的舒畅。代价是什么已经无所谓了，更多！还要更多的敌人…

原本游刃有余的战斗招式…现在连回想起来都费劲。

无法遏制的破坏欲凌驾于理性之上，只有将其填满的瞬间才能获得一丝宽慰。

惊恐在记忆中的阴影中蛰伏着，沉睡着，并将随着下一次无法控制的剧烈心跳再次苏醒。

当彻底认识到自己的渺小后，躲避的步伐变得踉跄无力，进攻的尝试顿觉毫无意义。

因「相像」而狐疑，因「不是」而崩溃。

此乃不可直视的「绽放」。无法用常识理解的诡异构造体抖动着令人目眩的「花瓣」，朦胧间，你与那绮丽而致命的花朵正一同在空中起舞，而地上呆若木鸡的人又是谁？

以太侵蚀如空气一般，渗透进了每一个人的体内。不论是生命体还是机械，都难以逃脱。
