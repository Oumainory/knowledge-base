# 「扳机」—敲敲通讯

- **「扳机」：** 绳匠，我在「芝托邦」门口等了你很久。最后有些饿了，我就进去报了你的名字。

- **「扳机」：** 卡萨女士听到你的名字后，告诉我这顿饭免单。但我付了她丁尼…并告诉她，下次绳匠到店里用餐的时候，记得把酱料全换成特辣的。

- **「扳机」：** 请不要忽视防卫军人的真心，否则这就是后果。

- **「扳机」：** 没事，我知道绳匠不会无故放我鸽子的。我还一度担心你是不是遇上了什么麻烦…还好并没有。

- **「扳机」：** 那，下回可要好好赴约哦。

- **主角（哲／铃）：** 去「厄匹斯港」吹吹风？

- **「扳机」：** 港口那边？绳匠，我们总能想到一块去呢。

- **「扳机」：** 走在登船口的木板上，感受海风，再吹上一会儿口琴…我很喜欢这样，会让我想起很多往事。

- **「扳机」：** 啊，这只是我设想的安排…绳匠，你会觉得无趣吗？

- **「扳机」：** 那就好…那让我们在港口步道汇合吧。我什么时候都方便的。

- **「扳机」：** 我准备了一首口琴曲，本来想吹给你听的…但你没有来。

- **「扳机」：** 绳匠，是有什么急事吗？还是跟其他人有约了？

- **「扳机」：** 我知道绳匠不会故意不来的。但如果能提前告知我…

- **「扳机」：** 不过我也习惯独自吹海风练习口琴了，请不要太在意。

- **「扳机」：** 我们下回再约吧，绳匠。

- **「扳机」：** 绳匠，不知你的录像店有没有这样一部电影…

- **「扳机」：** 真的吗？可我还没说是什么电影…

- **「扳机」：** 《次元枪神》。我听说这部片的录像带版本很是罕有…你们店里有吗？

- **「扳机」：** 不愧是绳匠。果然来问你是正确的。

- **「扳机」：** 那是我很多年前看过的电影…最近听「鬼火」队长提起来，突然有点想再看一次了。
